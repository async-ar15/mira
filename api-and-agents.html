01 — The Agent Swarm

Specialized Perspectives

Instead of asking a single prompt to do everything, MIRA fans out to four parallel agents, each with a specific prompt, system persona, and context retrieval strategy.

Security Agent (Gemini Pro)

Hunts for vulnerabilities, hardcoded secrets, and injection flaws. Given the highest context weight and uses the more expensive Pro model.

Quality Agent (Gemini Flash)

Focuses on cyclomatic complexity, DRY principles, and adherence to established patterns within the local codebase context.

Test Agent (Gemini Flash)

Checks if new logic is covered by existing tests, or if edge cases are missing from the newly added test suites.

Docs Agent (Gemini Flash)

Ensures that docstrings and README changes stay in sync with the underlying structural changes.

⚠
Agent Timeouts: To prevent runaway costs and hanging queues, all Flash agents have a strict 90s timeout. The Security agent (Pro) has a 120s timeout. If an agent times out, the Aggregator marks its score as 0.
02 — Authentication

Role-Gated Access

MIRA's dashboard and API are protected by JWT authentication via `python-jose`. The `users` table in Tiger Cloud supports three distinct roles.

Role Capabilities Endpoints Accessed
Viewer Read-only dashboard, metrics, and basic events. GET /auth/me
GET /api/v1/events
Reviewer Trigger manual reviews, clear HITL queue. POST /api/v1/trigger
POST /api/v1/hitl/resolve
Admin Manage users, access economics/costs, trigger exports. GET /api/v1/economics
GET /api/v1/calibration
GET /api/v1/export
Python backend/auth/jwt.py 
from fastapi import Depends, HTTPException
from auth.models import User

def require_admin(current_user: User = Depends(get_current_user)):
    if current_user.role != 'admin':
        raise HTTPException(status_code=403, detail="Admin access required")
    return current_user
03 — Data Export

Compliance Exports

For SOC2 or internal audit compliance, admins can generate cryptographic bundles of all agent findings and HITL decisions.

  1. 01

    Request the Export

    The admin calls GET /api/v1/export?pr_id=123&scope=full.

  2. 02

    S3 Upload & ZIP

    MIRA queries Tiger Cloud, serializes the events to JSON, packages them in a ZIP, and uploads it to the Object-Locked S3 bucket.

  3. 03

    Receive Pre-Signed URL

    The API responds with a temporary download link: {"download_url": "https://s3.../export-abc.zip?Expires=3600"}

04 — Calibration

Self-Improving Feedback Loops

The /api/v1/calibration endpoint powers the Calibration Dashboard. Every time a human resolves a HITL review in Slack, that decision is logged. A nightly ARQ job aggregates these human verdicts against the original agent scores to calculate "Agent Agreement Rates", continuously refining our auto-routing logic.
