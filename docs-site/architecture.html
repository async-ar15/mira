01 — The Review Lifecycle

From PR to Feedback

When a PR is opened, a GitHub webhook triggers the FastAPI receiver. The heavy lifting is immediately offloaded to a Redis-backed ARQ queue to prevent timeouts.

ℹ
Idempotency: The FastAPI receiver implements strict idempotency checks against Tiger Cloud. If GitHub retries a webhook delivery while the ARQ worker is still processing the code, the duplicate is dropped.

02 — The Data Layer

Tiger Cloud & Compliance

MIRA consolidates its vector search (for codebase context) and event tracking (for audit trails) into a single PostgreSQL-compatible datastore: Tiger Cloud.

Vector Search
Uses DiskANN in Tiger Cloud for lightning-fast retrieval of code chunks (`context_retriever.py`). We fully swapped out Qdrant to reduce operational complexity.
Event Logging
Every agent thought process, confidence score, and API cost is logged to a hypertables-backed `agent_events` table for dashboard analytics.
S3 Export
A nightly ARQ cron job purges old events, bundles them into ZIP files, and ships them to an AWS S3 bucket with Object Lock (7-year retention) for strict compliance.
